**FinanzFlow** es una aplicación web moderna y minimalista para el control de ingresos, gastos, presupuestos mensuales y metas de ahorro. Diseñada con una estética *fintech* limpia, ofrece visualización de datos en tiempo real y persistencia local sin necesidad de servidores externos.

## ✨ Características Principales

* **📊 Dashboard en Tiempo Real:** Cálculo automático de balance disponible, ingresos totales, gastos y tasa de ahorro con indicador de salud financiera.
* **🍩 Gráficos Interactivos:** Distribución visual de gastos por categoría mediante **Chart.js**, actualizado dinámicamente al añadir o eliminar movimientos.
* **🎯 Presupuestos Inteligentes:** Control de límites mensuales por categoría con alertas visuales progresivas (verde, ámbar y rojo) según el porcentaje consumido.
* **🐷 Huchas / Metas de Ahorro:** Creación de objetivos financieros personalizados con botones de aportación rápida (`+25 €`, `+50 €`, `+100 €`).
* **🔍 Filtros y Búsqueda Instantánea:** Filtra movimientos por tipo (ingresos/gastos), categoría o búsqueda por texto en tiempo real.
* **🌓 Modo Claro y Oscuro:** Cambio de tema fluido con detección de preferencias y guardado automático.
* **📥 Exportación a CSV:** Descarga el historial completo de transacciones listo para abrir en Excel o Google Sheets.
* **💾 Persistencia Local:** Almacenamiento automático en `localStorage` para conservar los datos entre sesiones sin registro ni backend.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico**
* **Tailwind CSS** (vía CDN) para un diseño *responsive* y utilitario.
* **JavaScript (ES6+)** puro (Vanilla JS) para toda la lógica de negocio, estado y manipulación del DOM.
* **Chart.js** para la visualización de datos financieros.
* **Lucide Icons** para iconografía minimalista y consistente.
